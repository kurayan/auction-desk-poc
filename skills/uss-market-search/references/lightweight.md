# 一覧からの照合と再開

- 新規・更新の履歴かキャッシュがあれば、リポジトリで `python scripts/market-db.py sync <Siteのdist/history> <非公開キャッシュディレクトリ>`。既存分は `python scripts/market-db.py find 型式 --summary` で所在と件数を見る。この件数には未成約・期間外も含む。判定用には `python scripts/market-db.py export market-cache/reuse.json` を使い、鮮度・成約・条件一致を個票で確認する。公開後は追加履歴を同期する。
- 通常TOP3は取得済み一覧から候補群を選び、対象会場・型式で下見検索、型式・年式で不足相場をまとめて検索する。同じ検索結果を複数の候補に使う。全件指定時は対象ページを網羅する。
- テキスト一覧から車両行を取得する。ページ送り直後は範囲表示と車両行の両方が新しいことを確認し、会場・開催日・出品番号で重複を除く。取得途中のページは完了扱いにしない。
- 検索群ごとに対象日・会場・条件・期間・取得日時、総数／確認数、成約個票と次の未取得位置を非公開の作業ファイルに保存する。会話に返すのは件数・中央値・不足条件・再開位置。個票は候補別の根拠に再利用する。サイト切替・再ログイン後は掲載会場と対象日を再確認する。
- 出品票は上位候補から開く。詳細で判明した実走行やグレードで再照合する。故障・修理費を記録し、候補が条件から外れたら次点を確認する。ページ全体や全行の再出力は、抽出不良の診断時に限る。
