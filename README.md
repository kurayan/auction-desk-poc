# Auction Desk PoC

Siteの検索ボタンからローカルChrome拡張に調査を依頼する、オークション間の車両価格比較PoC。GPT API・APIキー・別サーバーは不要です。

**実装済み・実機PoC待ち**：拡張の実装、比較ロジックのテスト、Web接続画面を用意しています。拡張を実際のChromeに読み込んでの通し検証は未完了です。サイト側の画面変更や認証方式によって停止する可能性があります。停止時には理由を表示し、未取得データでランキングを作りません。

## 最初の実行

1. リポジトリをダウンロード・展開します。
2. Chromeの拡張機能管理でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から `extension` を選びます。
3. 同じChromeプロファイルでTC-Webへログインします。CISはUSBキーを接続し、ログイン後に「相場検索」を開きます。
4. 拡張アイコンを開き、拡張IDをコピーします。
5. [Auction Desk](https://auction-desk-prototype-261111.leafycycle4.chatgpt.site) の接続設定にIDを入力し「接続する」。拡張追加前からSiteを開いていた場合は再読み込みします。
6. 関東／プリウス／上限100万円／TOP3で検索します。両社の価格基準が未確認なら価格差は保留になります。
7. 検索中はSiteを開いたままにします。認証待ちなら開かれた検索用タブでログインし、Siteの「ログイン後に再開」を押します。

## 対象と判断ルール

- TC-Web掲載の **TAA関東・JU神奈川** の出品と成約。JUナビ単独と関東全会場は対象外。
- 車種はプリウス。任意で型式を追加できます（例 `プリウス ZVW50`）。商用車は対象外。
- CISは候補の型式を最大4種類、画面で「過去4開催」が確認できる検索結果から収集。
- 1検索につき設定ページ数まで。1出品ページにつき条件に合う最大20台の詳細を確認。全市場のTOPではなく取得範囲内の順位です。
- 同一型式・グレード・色、年式±1年、距離±2万km、評価点±0.5の**落札済み**だけを比較。R/RA・流れを混ぜません。
- 仕入れ・売却それぞれ最低件数を要求。スタート価格から仕入れ額を推定しません。
- 仕入れ成約の最高額が予算以内、売却最低額−仕入れ最高額が正で、出品番号と開催日がある案件のみ条件付き候補。
- 価格基準はユーザーが両社の税区分・車両本体範囲を確認して設定。未確認時は差額を非表示。費用控除前であり、入札上限・利益の保証ではありません。
- 装備・出品票・機関状態・内外装の細部は未評価。入札前に人が確認してください。

## 構成

|場所|役割|
|---|---|
|web/|条件設定・進行・結果・JSON/CSV出力|
|extension/worker.js|保存可能な検索状態、認証待ち・再開・中止|
|extension/adapter.js|TC-Web/CISの表示項目と検索ボタン操作|
|extension/core.js|表の変換・類似成約照合・保留判定|
|tests/|合成データによる変換・予算・根拠・接続境界のテスト|
|skills/auction-desk-poc/|調査・実装保守・Sheets登録の運用指示|

ログイン情報の設定画面は設けず、ブラウザの既存セッションを使用します。Cookie・パスワード・USBキー情報を読み取りません。拡張権限はTC-Web/CIS、タブ操作、ローカル保存、スクリプト挿入です。Site側から任意URLや任意コードを渡す機能はありません。結果は拡張のローカルストレージに最新1件を保存し、許可されたSite内で表示します。自動クラウド送信、入札・購入操作はありません。

検索タブを変更すると検索の不一致で止まります。再開は現在の検索を先頭からやり直し、取得済み成約は重複を除外します。中止後のタブは確認のため残します。画面レイアウトを読み取れない場合、推測して続けず修正が必要です。

## 開発・検証

Node.js 20以上。追加パッケージ不要。

```sh
npm test
npm run serve
npm run package
```

ローカル表示は http://localhost:4173 。拡張を読み込むのは `extension/` または生成された `artifacts/auction-desk-connector/`。フォルダを移動すると拡張IDが変わる場合があります。

実機の受け入れ確認：接続 → 検索タブ作成 → 出品番号取得 → TC成約 → CIS成約 → 根拠付き結果 → JSON/CSV出力。追加で認証切れ→再開、中止、Site再読込、比較不足0件を確認してください。テスト用合成データは実際の市場データではありません。

Siteの公開URLを変更する際は `manifest.json` の externally_connectable と `worker.js` の許可元、popup.htmlを同時に変更します。Chrome公式仕様：[Webページとのメッセージ通信](https://developer.chrome.com/docs/extensions/develop/concepts/messaging#external-webpage)、[スクリプト挿入](https://developer.chrome.com/docs/extensions/reference/api/scripting)。

Google Sheetsへの自動登録はこの拡張には含みません。JSON/CSV出力、または同梱スキルと接続済みGoogle Driveを使う運用です。認証情報や実際の成約データはGitに追加しないでください。
